Overview & Evaluation Formulas

The Iris dataset is a multiclass dataset containing 150 instances of three iris species (Setosa, Versicolor, and Virginica). The data was partitioned into an 80% training set (120 samples) and a 20% test set (30 samples) using a fixed random seed (42).

Accuracy

Accuracy = (Correct Predictions) / (Total Predictions)

Overall fraction of test samples where the predicted class equals the true class.

Precision

Precision = True Positives / (True Positives + False Positives)

Measures what proportion of positive identifications was actually correct.

Recall

Recall = True Positives / (True Positives + False Negatives)

Measures what proportion of actual positive samples was identified correctly.

F1-Score

F1 = 2 × (Precision × Recall) / (Precision + Recall)

The harmonic mean of precision and recall, balancing false positives and false negatives.
